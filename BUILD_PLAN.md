# Build Plan

## Phase 0 — Repository and assets
- Create a new GitHub repository named `aditya-portfolio`.
- Add this brief and docs.
- Create a Vite React TypeScript app.
- Add the approved portrait to `public/images/aditya-portrait.png` when available.
- Keep secrets and private client data out of the repository.

## Phase 1 — Foundation
- Install and configure Tailwind CSS.
- Establish design tokens and typography.
- Create responsive page shell, navigation and footer.
- Verify the app runs locally.

## Phase 2 — Intro and hero
- Implement skip-friendly intro with reduced-motion support.
- Build responsive hero with portrait, tagline and calls to action.
- Add a lightweight orbital visual and fallback.

## Phase 3 — Portfolio sections
- About
- Featured projects driven from a data file
- Skills and verified experience
- Resume / LinkedIn services
- Contact

## Phase 4 — Polish
- Mobile and keyboard testing
- Check links and form behaviour
- Optimise images and lazy-load 3D
- Add metadata, favicon and social preview
- Verify build and deployment on Vercel

## Acceptance checklist
- [ ] `npm run dev` works
- [ ] `npm run build` passes
- [ ] All links are correct
- [ ] No invented metrics or unverified claims
- [ ] Intro can be skipped
- [ ] Reduced-motion preferences are respected
- [ ] Responsive on mobile, tablet and desktop
- [ ] Heavy visuals have a fallback
- [ ] README explains setup and deployment
